
# Python ATM System

## About the Project
This is a simple ATM System project created using Python and Excel.

## Features
- Create a new account
- Initial balance of Rs. 500
- Deposit money
- Withdraw money
- Check account balance
- Store account data in an Excel file

## Technologies Used
- Python
- Openpyxl
- Excel

## How to Run
1. Install Python.
2. Install openpyxl using `pip install openpyxl`.
3. Run the Python file.
4. Choose an option from the ATM menu.

## Purpose
This project is created for learning Python programming and file handling.
